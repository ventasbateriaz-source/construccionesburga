# Construcciones Burga — web inicial

Proyecto HTML, CSS y JavaScript para la web de Construcciones Burga.

## Abrir en Visual Studio Code
1. Descomprime la carpeta.
2. En VS Code, usa Archivo > Abrir carpeta y selecciona `construcciones-burga`.
3. Abre `index.html`.
4. Si tienes Live Server instalado, haz clic derecho y selecciona “Open with Live Server”.

## Logotipo
Coloca el logotipo oficial en:
`imagenes/logo/logo-burga.webp`

Usa webp con fondo transparente si tienes esa versión. Si tu archivo tiene fondo blanco, también funcionará, pero se verá el rectángulo blanco sobre el pie de página azul.

## Fotografías
Cambia los archivos de muestra indicados en `IMAGENES-LEEME.txt` por fotos propias o imágenes autorizadas. Respeta exactamente los nombres de archivo, extensión y carpeta.
